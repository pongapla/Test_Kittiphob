# Queue Management System
## Technical Assignment - ThaiBev

### 1. Technology Stack
- Frontend: Vue 3, TypeScript, Vite
- Backend: Go, Chi Router
- Database: SQLite
- API: REST / JSON
- Unit & Integration Tests: Go Test
- E2E Tests: Playwright

### 2. Application Screens

#### IT 05-1: Queue Reception
- Display a button to request a queue ticket.
- Display a button to reset the queue.
- Request a new queue number from the backend.
- Navigate to IT 05-2 after receiving a ticket.

#### IT 05-2: Queue Ticket
- Display the issued queue number.
- Display the ticket's issue date and time.
- Provide navigation back to IT 05-1.
- Refreshing the page must not issue a new ticket.

#### IT 05-3: Queue Reset
- Display a reset button.
- Reset the queue sequence.
- Display "00" after successful reset.
- Provide navigation back to IT 05-1.

### 3. Queue Number Rules
- Queue sequence starts at A0.
- Sequence: A0, A1, ... A9, B0, ... Z9.
- Maximum: 260 queue numbers per cycle.
- After Z9, reject new ticket requests until reset.
- After reset, the next queue must be A0.
- Queue numbers must be generated by the backend.

### 4. Data Integrity
- Use SQLite for persistent storage.
- Queue issuance must be atomic.
- Concurrent requests must not receive duplicate
  numbers within the same queue cycle.
- Reset and issuance must be serialized safely.
- Each ticket has a unique ID and issue timestamp.
- Reset starts a new queue cycle.
- Previous ticket records must not be confused
  with tickets issued after a reset.

### 5. Proposed API
POST /api/queues
GET  /api/queues/current
GET  /api/queues/{id}
POST /api/queues/reset

### 6. Error Handling
- Return appropriate HTTP status codes.
- Return structured JSON error responses.
- Handle queue exhaustion.
- Handle invalid ticket IDs.
- Handle database failures safely.

### 7. Testing
- Unit tests for queue sequence.
- Integration tests for issuance and reset.
- Concurrency tests for simultaneous requests.
- E2E tests for all three application screens.

### 8. Assumptions
- Queue issuance starts at A0.
- Queue sequence does not automatically wrap.
- Reset starts a new cycle.
- Reset is allowed without authentication for
  this assignment unless otherwise specified.
- These assumptions must be reviewed against
  the original assignment before final submission.
